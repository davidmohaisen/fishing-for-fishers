# Experimental reproducibility

The paper compares explicit transaction features and implicit address-level behavioral features in graph convolutional networks. It reports an 80/20 split and describes feature extraction, graph construction, normalization, and weighted loss.

**Not yet included:** Original experiment code, exact data splits, feature matrices, graph edges, model checkpoints, training configuration, and evaluation scripts. These should be added from the original research artifacts rather than reconstructed and presented as original.

When adding these files, specify the label granularity (transaction vs address), graph construction rules, data splitting unit, random seeds, feature scaling fit scope, and expected metrics.
